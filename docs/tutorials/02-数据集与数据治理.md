# 数据集与数据治理

## 学习目标

理解为什么训练文本必须带有来源、版本、许可证、语言和哈希，而不仅是一列 `text`。

## 前置条件

- 使用只包含公开、可记录来源的文本。
- 训练集与验证集在训练前固定。

## 原理

每条 JSONL 记录必须含有 `text`、`source`、`revision`、`license_note`、`language`、`split` 与 `document_hash`。清单验证会拒绝缺失字段、非法切分或重复哈希，从而避免未授权数据和训练/验证泄漏。

## 执行命令

```powershell
python -c "from pathlib import Path; from sinogpt.data.manifest import validate_manifest; print(validate_manifest(Path('data/manifests/train.jsonl')))"
```

## 预期输出

输出经过验证的记录列表；缺少许可证说明时会显示 `license_note` 错误。

## 常见故障

- `duplicate document_hash`：同一文档重复出现，必须在训练前去重。
- `split must be train or validation`：切分名称只能是这两个值。

## 复现实验证据

冻结 JSONL 的哈希、数据集 revision 和处理脚本版本。
