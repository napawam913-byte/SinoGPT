# 训练分词器

## 学习目标

训练并检查一个能够直接处理中文与英文文本的 BPE tokenizer。

## 前置条件

- 已通过 provenance 校验的训练 JSONL 清单。
- Python 环境已安装项目依赖。

## 原理

ByteLevel BPE 从字节级表示学习常见子词。项目固定保留 `<pad>`、`<bos>`、`<eos>` 与 `<unk>`，并将 `tokenizer.json` 作为所有实验共享的冻结输入。

## 执行命令

```powershell
python -m sinogpt.cli.train_tokenizer --manifest data/manifests/train.jsonl --output artifacts/tokenizer.json --vocab-size 50000
```

## 预期输出

命令写出 `artifacts/tokenizer.json`，并打印清单记录数。

## 常见故障

- `vocab_size must reserve all special tokens`：词表必须至少容纳四个保留 token。
- JSONL 校验失败：先按上一章补齐 provenance 字段。

## 复现实验证据

保存 tokenizer 文件的 SHA-256、训练清单 revision 和词表大小。
