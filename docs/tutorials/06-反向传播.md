# 从交叉熵到 AdamW：反向传播

## 学习目标

沿本项目的计算图理解损失梯度如何经过 Softmax、权重共享输出头、Pre-LN Block、GELU 和注意力回传，并知道 AdamW 实际更新了什么。

## 前置条件

- 已阅读 `04-GPT3架构.md` 和 `05-前向传播.md`。
- 已能运行 `python -m pytest tests/test_model.py -v`。

## 原理

对位置 `t` 的 logits `z_t`，交叉熵对 logits 的第一步梯度是：

`∂L/∂z_t = Softmax(z_t) - one_hot(y_t)`

这会先回传到 LM Head 与最终 LayerNorm。由于本项目将 `lm_head.weight` 与 `token_embedding.weight` 绑定，输出预测产生的梯度和输入嵌入查表产生的梯度会累积到同一个参数矩阵。

对每个 Pre-LN Block，残差 `x + f(LN(x))` 会让梯度分为恒等支路和子层支路，再在加法处相加。MLP 支路为：

`Linear(d,4d) ← GELU ← Linear(4d,d)` 的反向顺序。

其中精确 GELU 为 `0.5a(1 + erf(a/√2))`；它是 MLP 的激活函数。注意力中的 Softmax 是权重归一化，不是 GELU；LayerNorm 与残差也不是激活函数。

注意力支路的反向顺序是输出投影、`AV`、注意力 Softmax、已掩码的 `QKᵀ/√d`、再拆回 Q/K/V 线性投影。被因果掩码遮住的位置在前向分数为 `-∞`，不会得到允许“看未来”的注意力路径。

```mermaid
flowchart BT
    L[交叉熵 L] --> Z[dL/dlogits = Softmax(logits)-one_hot(label)]
    Z --> H[LM Head 与 Final LayerNorm]
    H --> R2[残差相加：梯度分到恒等支路和 MLP 支路]
    R2 --> D[Linear 4d→d]
    D --> G[GELU 导数]
    G --> U[Linear d→4d]
    U --> R1[残差相加：梯度分到恒等支路和注意力支路]
    R1 --> O[注意力输出投影]
    O --> AV[AV 乘法]
    AV --> S[Softmax 与因果掩码]
    S --> QKV[Q、K、V 线性投影]
    QKV --> E[Token/Position Embedding]
    E --> A[AdamW 更新参数]
```

在每个优化步，本项目先完成全部梯度累积，再计算并裁剪全局梯度范数到 1.0，最后执行 AdamW。简化写法为：

`m←β1m+(1-β1)g; v←β2v+(1-β2)g²; θ←θ-η(m̂/(√v̂+ε)+λθ)`

## 预期输出

测试应证明 `model.blocks[0].mlp.up.weight.grad` 存在且所有元素有限；训练器输出 `loss` 和裁剪前 `global_grad_norm`。

## 常见故障

- `non-finite causal language-model loss`：先停止训练并保存最近 checkpoint；检查数据 token ID 是否落在词表范围、学习率、bf16 支持和梯度范数。
- 梯度为 `None`：检查损失是否实际依赖该参数，或是否在错误位置调用了 `detach()`/`no_grad()`。
- 恢复后曲线突变：确认 checkpoint 同时包含模型、优化器、调度器、游标和 RNG 状态。

## 复现实验证据

记录每一步的 `loss`、`global_grad_norm`、`tokens_per_second`、`peak_memory_bytes` 和 `tokens_seen`；保存对应 checkpoint 文件名与全局步数。
