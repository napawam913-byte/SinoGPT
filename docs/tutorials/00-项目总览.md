# SinoGPT 项目总览

## 学习目标

完成一个可以审计、可以恢复、可以写成论文式报告的 GPT-3 风格中英双语训练项目；重点是掌握方法与证据链，而非声称复现 175B GPT-3。

## 前置条件

- 云端单卡 RTX 4090、64GB 内存、100GB 系统盘，以及可用于原始数据和长期 checkpoint 的外部存储。
- Python/CUDA 环境与本仓库代码。
- 可明确记录来源、revision 和许可证的训练语料。

## 原理

项目采用 decoder-only、Pre-LN Transformer：ByteLevel BPE → token/位置嵌入 → 因果多头注意力 → GELU MLP → 交叉熵 → AdamW。训练分为三个层级：约 30M 教学模型验证链路（`tiny_25m` 是历史目录名；程序统计为 29,853,696 个可训练参数）、125M 控制变量消融研究数据配比，350M 在单卡约束下完成主实验。

这不是“中文先翻译为英文”的模型。中文能力来自 tokenizer 能有效编码中文、训练语料中有足够的中文 token，以及训练目标直接预测中文下一个 token。

## 执行命令

按章节顺序执行：

```bash
python -m pip install -e ".[dev]"
python -m pytest -v
python -m sinogpt.cli.train_tokenizer --manifest data/manifests/demo_train.jsonl --output artifacts/tiny_25m_demo/tokenizer.json --vocab-size 50000
python -m sinogpt.cli.prepare_data --config configs/tiny_25m_demo_stage1.yaml
python -m sinogpt.cli.train --config configs/tiny_25m_demo_stage1.yaml --device cpu
python -m sinogpt.cli.train --config configs/tiny_25m_demo.yaml --resume artifacts/tiny_25m_demo/checkpoints/step_10.pt --device cpu
```

云端真实运行应改用 `configs/tiny_25m.yaml`，保持 `block_size: 512` 和 `use_bf16: true`。

## 预期输出

项目目录应产生可忽略的大型运行产物 `artifacts/`、可再生数据缓存 `data/cache/` 与版本控制的代码、manifest、配置和教程。demo 验收运行实际得到 20 条有限 loss，两个 checkpoint（第 10、20 步）和可恢复训练记录。

## 常见故障

- 不要用 demo 语料的 loss 或采样质量得出中文能力结论。
- 云端 100GB 系统盘不够存放完整语料与历史 checkpoint；应使用对象存储或数据盘。
- 真正开始 125M/350M 前，必须先完成许可证审计和 immutable run manifest。

## 复现实验证据

每个运行收集 Git commit、环境版本、配置、tokenizer/manifest 哈希、随机种子、指标 JSONL、checkpoint URI 和评测输出。
